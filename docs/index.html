核心特性

Ping0 + IPPure 双源检测

同时查询两家评分，分别显示 IP 类型、原生／广播标记和失败原因。一家失败不会丢弃另一家的结果。

全自动运行

通过 Clash External API 自动切换节点并逐个测试。无需人工干预，支持单节点重测。

智能重写配置

测试结果自动追加到节点名称后，支持更新 Proxy Groups。输出即用，无需手动修改配置文件。

Docker 容器部署

提供 Docker 部署方案，与本地环境隔离开箱即用，适合在 NAS 或服务器上稳定运行。

隐私保护

完全开源，代码透明可审计。节点信息仅在本地处理或自己的服务器上处理，保障你的订阅隐私。

结果解读

双源模式使用两家的独立评分，例如 【Ping0 20%｜IPPure 35%】。 一家超时会显示 【Ping0 超时｜IPPure 35%】，另一家的分数仍会保留。 两家出口 IP 不同时显示“出口 IP 不一致”。分数越低越好，不计算平均分或总分。 住宅／机房是 IP 类型，原生／广播是 IP 来源；两者是不同字段。

🟢

纯净

两家评分都低，IPPure 的 Bot 比例也低，适合注册、登录等敏感操作。

🟡

一般

至少一家评分偏高，或 Bot 比例适中；日常浏览通常够用。

🔴

高危

两家评分都高，或一家明确标记为高风险；可能影响流媒体解锁和账号操作。
